# Validation plan

The frozen fixture contains seven events spanning objective, constraint, decision, tool observation, secret, rejected action and pending work. The destination has internal clearance and a fixed token budget.

Compare: combined, no RuVector, no RVF, no tiktoken, no conformal control, enterprise-only, and Ruvnet-only. Measure selected events, exact token use, recall availability, cryptographic evidence, conformal gating, replayed decisions and tamper rejection. Seeds, calibration residuals and event order are fixed in source. Raw command outputs belong under `evidence/raw/`; summarized results must link back to those files.
